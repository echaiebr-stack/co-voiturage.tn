# co-voiturage.tn — Frontend Design System v1.0
Status: FINAL • FROZEN

## Visual direction
Premium, modern, human and mobility-oriented. Avoid generic admin/SaaS appearance. Strong hierarchy, generous whitespace, confident typography, clear trust signals and purposeful motion.

## Foundations
Tokenize color, typography, spacing, radii, shadows, elevation, breakpoints and motion. No page-specific magic values when a token exists.

## Core components
Buttons, inputs, selectors, date/time controls, trip cards, profile blocks, vehicle blocks, booking status, alerts, dialogs, toasts, skeletons, empty states, navigation, bottom navigation, message composer.

## Trip card minimum information
Origin, destination, date/time, price, available seats, driver identity, rating, trust indicators, primary action.

## Navigation
Mobile: Search, Publish, Trips, Messages, Profile.
Desktop: logo, Search, Publish, Trips, Messages, Notifications, Profile.

## Accessibility
Visible labels, keyboard navigation, focus states, semantic HTML, sufficient contrast, error text plus visual state, touch-friendly controls, reduced-motion support.

## Responsive/i18n
Mobile-first. Support desktop expansion. French, Arabic and English. RTL is a first-class layout mode.

## Lovable rules
Lovable may implement UI only within this system and approved UX/API contracts. It must not invent backend business rules, change data models or silently alter API semantics.
