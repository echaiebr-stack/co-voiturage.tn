# co-voiturage.tn — User Journeys v1.0
Status: FINAL • MVP

## Passenger journey
Home → Search → Results → Trip Details → Login/Register → Booking Request → Booking Status → Messages/Notifications → Trip → Review.

## Driver journey
Profile → Vehicle → Create Trip → Review → Publish → Booking Requests → Accept/Decline → Messages → Complete Trip → Review.

## Guest journey
Home → Search → Results → Public Trip Details → Login/Register when an action requires identity.

## Trust journey
User/Profile → verification indicators → rating/reviews → report/block when needed → moderation outcome.

## Empty/error/loading rules
Every data-dependent page has loading, empty, error and retry states. Destructive actions require confirmation. No important workflow ends on a blank screen.

## Mobile
Primary actions remain reachable; touch targets are comfortable; no hover-only behavior; sticky actions may be used for booking/publishing.

## RTL
All layouts, icons, alignment, navigation, forms and directional interactions must support RTL without duplicated page implementations.
